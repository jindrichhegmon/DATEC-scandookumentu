    3 · Výsledek

    Historie (posledních 20)

    Prompty a historie se ukládají pouze v tomto prohlížeči; přístupový token si prohlížeč pamatuje, dokud aplikaci nezamknete v Nastavení.
    Dokumenty se odesílají ke zpracování do vašeho scénáře Make (ScanDokumentu_Vytezeni), případně přímo na Claude API.
    Každý dotaz a odpověď se ukládá do SQL databáze CLB1 (tabulka CLB_SCANN_DOKUMENTU) přes scénář ScanDokumentu_LogSQL.
    Odkazy na web načítá funkce nasazená spolu s tímto webem; pokud není k dispozici, zkusí se stránka stáhnout přímo z prohlížeče.

    🔐 Přístup do aplikace

    Aplikaci lze spustit až po zadání přístupového tokenu — buď interního tokenu DATEC‑SCAN, nebo vašeho Claude API klíče (sk-ant-…). Po úspěšném přihlášení si tento prohlížeč token zapamatuje a příště už ho nebude vyžadovat.

    ⚙️ Nastavení

    Dokument + prompt se pošlou do scénáře ScanDokumentu_Vytezeni ve vašem Make účtu. Model AI změníte přímo ve scénáři (modul „Run an agent").

    Klíč získáte na console.anthropic.com (Settings → API keys). Ukládá se pouze do tohoto prohlížeče.

    🗄️ Náhled záznamů v databázi

    Náhled do všech záznamů v tabulce CLB1 · CLB_SCANN_DOKUMENTU je chráněn heslem.
